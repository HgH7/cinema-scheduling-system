# Project Brief: Cinema Movie Scheduling System

## Project Overview
The Cinema Movie Scheduling System is a comprehensive desktop application designed to streamline the movie-going experience for customers and simplify administrative tasks for cinema staff. The system bridges the gap between movie discovery and ticket acquisition while providing powerful management tools for cinema operations.

## Target Audience
1.  **Moviegoers:** Tech-savvy individuals looking for a fast, intuitive way to browse movies, select showtimes, and book specific seats.
2.  **Cinema Admin/Staff:** Operators who need to manage the movie catalog, schedule screenings, and monitor theater occupancy and bookings.

## Design Goals
- **Cinematic Aesthetic:** A modern, high-contrast dark theme that evokes the feeling of a premium theater experience.
- **Clarity & Efficiency:** Minimizing clicks to complete a booking while providing admins with a clear overview of complex scheduling data.
- **Intuitive Seat Booking:** A visual-first approach to seat selection that mirrors the physical theater layout.
- **Role-Based Navigation:** A clear structural separation between the customer-facing "CineReserve" interface and the "Cinema Admin" management console.

## Core Features & User Flows

### 1. Moviegoer Experience (CineReserve)
- **Movie Discovery:** A visually rich gallery of currently playing and upcoming films with metadata (genre, duration, rating).
- **Showtime Selection:** A date-based scheduling view that allows users to find the most convenient screening time across different theater screens.
- **Interactive Seat Mapping:** A 2D grid representation of the theater with real-time status indicators (Available, Booked, Selected).
- **Booking Management:** Digital ticket generation with unique Booking IDs and the ability to cancel reservations within a specific timeframe.

### 2. Admin Experience (Cinema Admin)
- **Catalog Management:** Tools to add, edit, or remove movies from the system, including metadata and poster art.
- **Schedule Optimization:** A dedicated interface for assigning movies to specific screens and time slots, preventing scheduling conflicts.
- **Real-time Monitoring:** A dashboard for viewing all active bookings, tracking revenue, and managing user reservations.

## Technical Structure (UI/UX)
- **Navigation:** A persistent sidebar for the Admin flow and a modern top navigation bar for Moviegoers.
- **Consistency:** Powered by the "Cinematic Core" design system, ensuring uniform typography (Be Vietnam Pro), spacing, and color usage (#E50914 primary accent).
- **Layouts:** Use of cards for visual discovery and structured tables for data-heavy administrative tasks.

## Success Metrics
- Reduction in time-to-book for end users.
- Accuracy in seat allocation and scheduling.
- Ease of use for staff when updating daily movie listings.
